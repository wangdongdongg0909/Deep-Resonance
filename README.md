# 王延平新作：《深渊共鸣》系列丛书

这是一部由财经作家兼科幻创作者王延平撰写的系列丛书，探讨生成式 AI 时代下经济学思想实验与科幻叙述的交汇。

## 丛书书目与架构
- **核心作品**：《深渊共鸣》系列丛书
- **分册包含**：零点博弈、节点风暴、资产负债表、奇点归零、悖论回响、深渊共鸣外传：大山传
